# MiMoCode Guard 1.2 audit runbook

This branch adds a report-integrity gate before the next training round.

## Run on Kaggle CPU

```bash
!wget -q -O audit_v12_reports.py https://raw.githubusercontent.com/p5i6/mimocode-guard/mimocode-guard-1.2-audit/tools/audit_v12_reports.py
!python audit_v12_reports.py
```

The script uses Python's standard library only. Internet access must be enabled in Kaggle.

## Required review before retraining

Open `mimocode_guard_v12_audit/audit_summary.json` and verify:

- Every JSONL file parses with zero malformed lines.
- Each JSONL row count matches `error_analysis.json`.
- No normalized sample family appears in multiple data splits.
- The actual split distributions are understood; do not rebalance validation or test to make metrics look better.
- Keep test metrics report-only. Select models and thresholds using validation data only.

If any check fails, stop and repair the dataset/report export before training.

## Safety and model selection

- Keep Candidate A as the baseline; do not assume it is deployable.
- Compare a second candidate only on the same frozen train/validation/test split.
- Preserve the 10 MB package target and CPU-first training constraint.
- Do not lower the critical threshold merely to improve recall: the previous validation non-critical FPR was already about 19.98% against a 20% ceiling.
- Never use a model's `safe` result to authorize shell execution. Privileged actions require deterministic policy checks and explicit human approval.

## Scope

This audit script does not train, tune thresholds, change labels, or certify safety. It creates an auditable input-quality report for the next training stage.
